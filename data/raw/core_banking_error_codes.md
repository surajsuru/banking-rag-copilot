# Core Banking Error Code Reference Manual

## Overview
This document provides a comprehensive reference for all error codes generated by the core banking platform. Each error code includes the cause, severity level, and recommended resolution steps.

## Error Code Categories
- TXN: Transaction processing errors
- AUTH: Authentication and authorization errors
- ACC: Account management errors
- PAY: Payment gateway errors
- SYS: System and infrastructure errors
- AML: Anti-money laundering errors
- KYC: KYC verification errors
- INT: Integration and API errors
- REC: Reconciliation errors
- SEC: Security errors

---

## TXN — Transaction Errors

### TXN-1001
- Description: Insufficient account balance
- Severity: LOW
- Cause: The debit amount exceeds available balance in the account
- Resolution: Advise customer to add funds or reduce transaction amount
- Retry: No

### TXN-1002
- Description: Account daily limit exceeded
- Severity: LOW
- Cause: Transaction would breach the configured daily transaction limit
- Resolution: Customer must wait until next business day or request limit enhancement
- Retry: No

### TXN-1003
- Description: Transaction timed out
- Severity: MEDIUM
- Cause: Downstream system did not respond within the configured timeout (default 30 seconds)
- Resolution: Check downstream system health; retry after 5 minutes
- Retry: Yes (after status verification)

### TXN-1004
- Description: Duplicate transaction detected
- Severity: MEDIUM
- Cause: A transaction with the same reference ID was processed within the deduplication window (24 hours)
- Resolution: Generate a new unique transaction reference ID
- Retry: No

### TXN-1005
- Description: Transaction amount below minimum threshold
- Severity: LOW
- Cause: Attempted transaction amount is below the minimum allowed for this transaction type
- Resolution: Increase the transaction amount or use a different payment channel
- Retry: No

### TXN-1006
- Description: Transaction amount above maximum threshold
- Severity: MEDIUM
- Cause: Attempted transaction amount exceeds the maximum allowed
- Resolution: Split the transaction or request a limit review from operations
- Retry: No

### TXN-1007
- Description: Invalid currency code
- Severity: LOW
- Cause: The currency code provided is not recognized or not supported
- Resolution: Use a valid ISO 4217 currency code
- Retry: Yes (with corrected currency code)

### TXN-1008
- Description: Account frozen - debit blocked
- Severity: HIGH
- Cause: Account has been frozen by court order or compliance action
- Resolution: Contact compliance team; do not unfreeze without authorization
- Retry: No

### TXN-1009
- Description: Account frozen - credit blocked
- Severity: HIGH
- Cause: Account has been frozen against receiving credits
- Resolution: Contact compliance team; return credit to remitter
- Retry: No

### TXN-1010
- Description: Exchange rate not available
- Severity: MEDIUM
- Cause: FX rate feed is unavailable for the requested currency pair
- Resolution: Check FX rate feed connectivity; use last known rate if allowed by policy
- Retry: Yes (after 15 minutes)

### TXN-1011
- Description: Settlement account not configured
- Severity: HIGH
- Cause: No settlement account mapped for this transaction type
- Resolution: Contact operations to configure the settlement account mapping
- Retry: No

### TXN-1012
- Description: Transaction reversal window expired
- Severity: MEDIUM
- Cause: Reversal was attempted after the allowed reversal window (default 24 hours)
- Resolution: Process a manual credit through back-office; require manager approval
- Retry: No

### TXN-1013
- Description: Beneficiary account not found
- Severity: LOW
- Cause: Destination account number does not exist in the system
- Resolution: Verify account number with customer; check for typos
- Retry: Yes (with corrected account number)

### TXN-1014
- Description: IFSC code invalid
- Severity: LOW
- Cause: IFSC code not found in RBI master directory
- Resolution: Verify IFSC code on RBI website; check for recent bank mergers
- Retry: Yes (with corrected IFSC)

### TXN-1015
- Description: Transaction blocked by AML rule
- Severity: HIGH
- Cause: Transaction matches a configured AML pattern or threshold
- Resolution: Route to AML team for manual review; do not release without approval
- Retry: No

### TXN-1016
- Description: Maker-checker approval pending
- Severity: LOW
- Cause: High-value transaction is awaiting second-level approval
- Resolution: Notify checker to review and approve the transaction
- Retry: No (wait for approval)

### TXN-1017
- Description: Card expired
- Severity: LOW
- Cause: The payment card has passed its expiry date
- Resolution: Customer must use a valid card
- Retry: No

### TXN-1018
- Description: CVV mismatch
- Severity: MEDIUM
- Cause: Card Verification Value does not match bank records
- Resolution: Customer to re-enter correct CVV; card may be blocked after 3 failures
- Retry: Yes (maximum 3 attempts)

### TXN-1019
- Description: Card blocked by issuer
- Severity: HIGH
- Cause: Card has been blocked due to suspicious activity or customer request
- Resolution: Customer to contact issuing bank
- Retry: No

### TXN-1020
- Description: Network switch unavailable
- Severity: HIGH
- Cause: Payment switch (Visa/Mastercard/RuPay) is unreachable
- Resolution: Check network connectivity to payment switch; escalate if > 5 minutes
- Retry: Yes (after system recovery)

## AUTH — Authentication Errors

### AUTH-2001
- Description: Invalid credentials
- Severity: LOW
- Cause: Username or password does not match records
- Resolution: Customer to re-enter credentials; account locks after 5 failures
- Retry: Yes (maximum 5 attempts)

### AUTH-2002
- Description: Account locked due to multiple failed attempts
- Severity: MEDIUM
- Cause: User exceeded maximum login attempts
- Resolution: Customer must reset password or contact support
- Retry: No

### AUTH-2003
- Description: Session expired
- Severity: LOW
- Cause: User session exceeded maximum idle time (default 15 minutes)
- Resolution: User must log in again
- Retry: Yes (new session)

### AUTH-2004
- Description: OTP expired
- Severity: LOW
- Cause: One-time password exceeded validity window (default 5 minutes)
- Resolution: Request a new OTP
- Retry: Yes (new OTP)

### AUTH-2005
- Description: OTP mismatch
- Severity: MEDIUM
- Cause: Entered OTP does not match sent OTP
- Resolution: Re-enter OTP; 3 attempts allowed before OTP invalidation
- Retry: Yes (maximum 3 attempts)

### AUTH-2006
- Description: Token validation failed
- Severity: HIGH
- Cause: JWT or API token is invalid, expired, or tampered
- Resolution: Re-authenticate and obtain new token
- Retry: Yes (with new token)

### AUTH-2007
- Description: Insufficient privileges
- Severity: MEDIUM
- Cause: User does not have required role to perform this action
- Resolution: Request access from system administrator
- Retry: No

### AUTH-2008
- Description: IP address not whitelisted
- Severity: HIGH
- Cause: Request originated from an IP address not in the allowed list
- Resolution: Add IP to whitelist through security team; verify there is no unauthorized access
- Retry: No

## ACC — Account Errors

### ACC-3001
- Description: Account not found
- Severity: LOW
- Cause: Account number does not exist in core banking system
- Resolution: Verify account number; check if account was recently migrated
- Retry: Yes (with correct account number)

### ACC-3002
- Description: Account closed
- Severity: LOW
- Cause: Account has been closed and is no longer active
- Resolution: Return transaction to remitter with reason code
- Retry: No

### ACC-3003
- Description: Account dormant
- Severity: MEDIUM
- Cause: No transactions in the past 24 months; account is in dormant state
- Resolution: Customer must visit branch to reactivate account
- Retry: No

### ACC-3004
- Description: Account under lien
- Severity: MEDIUM
- Cause: A lien has been placed on the account balance
- Resolution: Check lien details; only allow transactions up to available non-lien balance
- Retry: Partial (up to available balance)

### ACC-3005
- Description: KYC not completed
- Severity: HIGH
- Cause: Customer has not completed KYC requirements; account is restricted
- Resolution: Notify customer to complete KYC within 30 days or account will be frozen
- Retry: No

### ACC-3006
- Description: Account type mismatch
- Severity: LOW
- Cause: Transaction type is not permitted for this account type
- Resolution: Use appropriate account for transaction type
- Retry: No

## PAY — Payment Gateway Errors

### PAY-4001
- Description: Payment gateway timeout
- Severity: HIGH
- Cause: Payment gateway did not respond within SLA (default 20 seconds)
- Resolution: Check gateway health dashboard; retry after 5 minutes
- Retry: Yes

### PAY-4002
- Description: Gateway connection refused
- Severity: CRITICAL
- Cause: Cannot establish TCP connection to payment gateway
- Resolution: Check network configuration; contact gateway provider; escalate immediately
- Retry: Yes (after network check)

### PAY-4003
- Description: Invalid merchant ID
- Severity: MEDIUM
- Cause: Merchant ID not found or not active in payment gateway
- Resolution: Verify merchant onboarding status; contact merchant support team
- Retry: No

### PAY-4004
- Description: Payment declined by issuer
- Severity: LOW
- Cause: Issuing bank has declined the payment
- Resolution: Customer to contact issuing bank; reason codes provided in gateway response
- Retry: No

### PAY-4005
- Description: 3DS authentication failed
- Severity: MEDIUM
- Cause: 3D Secure authentication was not completed or failed
- Resolution: Customer to retry with OTP; ensure 3DS service is available
- Retry: Yes

## SYS — System Errors

### SYS-5001
- Description: Database connection failed
- Severity: CRITICAL
- Cause: Cannot connect to primary database cluster
- Resolution: Check database health; failover to secondary if available; page DBA on call
- Retry: Yes (after failover)

### SYS-5002
- Description: Core banking system unavailable
- Severity: CRITICAL
- Cause: Core banking system (Finacle/Flexcube/BaNCS) is not responding
- Resolution: Check CBS health; notify operations; implement downtime procedures
- Retry: Yes (after CBS recovery)

### SYS-5003
- Description: Message queue full
- Severity: HIGH
- Cause: Transaction message queue has reached capacity
- Resolution: Scale queue consumers; check for processing bottleneck; purge if authorized
- Retry: Yes (after queue relief)

### SYS-5004
- Description: Disk space critical
- Severity: HIGH
- Cause: Server disk utilization above 90%
- Resolution: Archive old logs; expand disk; alert infrastructure team
- Retry: No (system-level action required)

### SYS-5005
- Description: Memory exhaustion
- Severity: CRITICAL
- Cause: JVM or process memory has been exhausted
- Resolution: Restart service; analyze heap dump; increase memory allocation
- Retry: Yes (after service restart)

## AML — Anti-Money Laundering Errors

### AML-6001
- Description: Transaction exceeds STR threshold
- Severity: HIGH
- Cause: Transaction amount or pattern triggers Suspicious Transaction Report requirement
- Resolution: Hold transaction; route to AML team within 2 hours
- Retry: No (pending AML review)

### AML-6002
- Description: Customer on PEP list
- Severity: HIGH
- Cause: Customer identified as Politically Exposed Person
- Resolution: Apply enhanced due diligence; require senior management approval
- Retry: No (EDD required first)

### AML-6003
- Description: Sanctioned country destination
- Severity: CRITICAL
- Cause: Beneficiary is in a country under OFAC or UN sanctions
- Resolution: Block transaction immediately; file regulatory report; escalate to compliance
- Retry: No

### AML-6004
- Description: Velocity check triggered
- Severity: MEDIUM
- Cause: Customer has exceeded transaction velocity limits (e.g., 10 transactions in 1 hour)
- Resolution: Soft block; manual review by AML team within 4 hours
- Retry: Conditional (pending review)

## KYC — KYC Verification Errors

### KYC-7001
- Description: Aadhaar verification failed
- Severity: MEDIUM
- Cause: UIDAI Aadhaar authentication was unsuccessful
- Resolution: Customer to retry; check UIDAI service status
- Retry: Yes (3 attempts per day)

### KYC-7002
- Description: PAN validation failed
- Severity: MEDIUM
- Cause: PAN number not found in Income Tax database
- Resolution: Verify PAN details; customer may need to update KYC records
- Retry: Yes

### KYC-7003
- Description: Video KYC session failed
- Severity: LOW
- Cause: Video call was disconnected or quality was insufficient
- Resolution: Reschedule video KYC session; check internet connectivity
- Retry: Yes

### KYC-7004
- Description: Document OCR failure
- Severity: LOW
- Cause: Document image quality is too low for OCR extraction
- Resolution: Customer to provide clearer document image; re-upload
- Retry: Yes

## INT — Integration Errors

### INT-8001
- Description: External API rate limit exceeded
- Severity: MEDIUM
- Cause: Too many requests to external API within rate limit window
- Resolution: Implement exponential backoff; check rate limit headers; cache responses
- Retry: Yes (after backoff period)

### INT-8002
- Description: Webhook delivery failed
- Severity: MEDIUM
- Cause: Merchant webhook endpoint returned non-200 status or timed out
- Resolution: Retry webhook delivery 3 times with exponential backoff; mark as failed after 3 attempts
- Retry: Yes (automatic)

### INT-8003
- Description: SSL certificate expired
- Severity: CRITICAL
- Cause: SSL/TLS certificate for external connection has expired
- Resolution: Renew certificate immediately; alert security team
- Retry: No (certificate renewal required)

### INT-8004
- Description: API version deprecated
- Severity: LOW
- Cause: Client is calling a deprecated API version
- Resolution: Notify client to migrate to current API version within 90 days
- Retry: Yes (works but with warning)

## REC — Reconciliation Errors

### REC-9001
- Description: Reconciliation mismatch - amount
- Severity: HIGH
- Cause: Transaction amount in CBS does not match settlement statement
- Resolution: Escalate to Finance and Operations; do not close reconciliation until resolved
- Retry: N/A (investigation required)

### REC-9002
- Description: Reconciliation mismatch - count
- Severity: HIGH
- Cause: Number of transactions in CBS does not match settlement statement
- Resolution: Compare transaction logs item by item; identify missing entries
- Retry: N/A

### REC-9003
- Description: Stale reconciliation data
- Severity: MEDIUM
- Cause: Reconciliation file not received from counterparty within expected time
- Resolution: Contact counterparty; use provisional reconciliation pending file receipt
- Retry: N/A

## SEC — Security Errors

### SEC-0001
- Description: SQL injection attempt detected
- Severity: CRITICAL
- Cause: Input contains SQL injection patterns
- Resolution: Block request; log IP; alert security team; review WAF rules
- Retry: No

### SEC-0002
- Description: XSS attempt detected
- Severity: HIGH
- Cause: Input contains cross-site scripting patterns
- Resolution: Block and sanitize input; alert security team
- Retry: No

### SEC-0003
- Description: Data encryption failure
- Severity: CRITICAL
- Cause: Encryption module returned error; data not encrypted
- Resolution: Do not transmit unencrypted data; halt operation; alert security team immediately
- Retry: No

### SEC-0004
- Description: HSM communication failure
- Severity: CRITICAL
- Cause: Hardware Security Module not responding
- Resolution: Failover to backup HSM; alert infrastructure team; do not process PIN transactions
- Retry: Yes (after HSM recovery)
